K-Means Clustering — Core Concepts

What is Unsupervised Learning?

Unsupervised learning is a type of machine learning where the algorithm is trained on unlabeled data — there is no predefined output variable. The goal is to discover hidden patterns, structures, or groupings within the data without human guidance.

Unlike supervised learning (where the model learns from labeled examples), unsupervised learning lets the data speak for itself.

Real-World Applications

  • Customer segmentation in marketing
  • Anomaly detection in cybersecurity
  • Document and topic clustering in NLP
  • Gene expression grouping in biology
  • Image compression and segmentation

What is Clustering?

Clustering is the process of grouping a set of data points so that points within the same group (cluster) are more similar to each other than to points in other groups. Similarity is typically measured by distance.

Key clustering algorithms include K-Means, DBSCAN, Hierarchical Clustering, and Gaussian Mixture Models.

What is K-Means?

K-Means is one of the most popular clustering algorithms. It partitions a dataset into K clusters by iteratively assigning points to the nearest centroid and updating centroids until convergence.

Algorithm Steps

  1. Choose K (number of clusters)
  2. Initialize K centroids randomly
  3. Assign each point to the nearest centroid
  4. Recalculate centroids as the mean of assigned points
  5. Repeat steps 3–4 until centroids stop changing

Key Concepts

Centroid

The center point of a cluster, calculated as the mean of all data points assigned to that cluster. It is updated each iteration.

Euclidean Distance

The straight-line distance between two points. For features x₁, x₂: d = √((x₁−c₁)² + (x₂−c₂)²)

Variance / Inertia

The sum of squared distances from each point to its assigned centroid. Lower variance means tighter, better-defined clusters.

Convergence

The algorithm converges when centroids no longer move significantly between iterations — meaning cluster assignments have stabilized.
